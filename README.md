### Job Tracker
Приложение на Java для управления пользователями и вакансиями с поддержкой истории команд.

#### Имеющаяся функциональность (24.03.26):
- создание пользователей и вакансий.
- вывод списка пользователей.
- парсинг CLI-команд с параметрами.
- сохранение истории команд в файл.
- восстановление состояния при запуске.
- команда history для просмотра ранее введённых команд.

##### Реализовано:
- task1_develop => CLI и команды, парсинг команд с помощью паттерна Strategy.
- task2_develop => реализована работа с файлами, логирование(абстрактное).

##### Стек:
* Java
* ООП
* Strategy pattern
